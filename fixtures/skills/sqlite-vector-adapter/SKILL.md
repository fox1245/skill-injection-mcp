# SQLite Vector Adapter

Dense retrieval adapter for storing embeddings and running vector similarity search.

## Capabilities
- sqlite-vector extension integration
- Upsert embedding vectors
- Cosine / L2 dense search
- Semantic retrieval over skill documents

## Notes
- Complements sparse BM25; together they enable hybrid retrieval
